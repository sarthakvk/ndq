# Parser Design

## I/O Contract

### Input

The parser takes a list of tokens generated by the lexer from the user's input.

### Errors

The parser raises a syntax error if the input does not match the [grammar rules](#grammar).

### Output

The parser returns an AST (abstract syntax tree) generated by parsing the token list. If the parser returns an AST, the query is syntactically valid and follows the [grammar rules](#grammar).

## Grammar

```ebnf
query = or_expr

or_expr = and_expr, {"|", and_expr}

and_expr = not_expr, {"&", not_expr}

not_expr = predicate | ("!", not_expr)

predicate = comp | "(", or_expr, ")"

comp = term, op, term

term = (field | value)

op = "=" | "!=" | "<" | "<=" | ">" | ">="

field = identifier, {".", identifier}

value = string | number | "true" | "false" | "null"
```
